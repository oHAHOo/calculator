# 🧮 계산기 만들기 

## 📌 프로젝트 소개
Java를 이용해 구현한 계산기 프로그램
사용자로부터 입력을 받아 사칙연산을 수행하고, 결과를 저장 및 출력한다

---

## 🚀 주요 기능

### 1. 계산 기능
- `+`, `-`, `*`, `/` 연산 지원
- 제네릭을 활용한 숫자 처리
- 0으로 나누기 예외 처리

### 2. 결과 저장
- 계산 결과를 리스트에 저장
- `Calculator` 클래스를 통해 관리

### 3. 결과 조회
- 지금까지 저장된 모든 계산 결과 출력

### 4. 가장 먼저 저장된 계산 결과 제거
- 가장 먼저 저장된 계산 결과 제거

### 5. 조건 필터링
- 특정 값 이상인 결과만 출력 (Stream + filter 사용)

---

## 🏗️ 프로젝트 구조
org.zerock

├── ArithmeticCalculator.java // 제네릭 기반 계산 로직

├── OperatorType.java // enum + 람다로 연산 정의

├── Calculator.java // 결과 저장 및 관리

## 🖥️ 실행 방법
1. 프로젝트 실행
2. 메뉴 선택
```java
1. 계산 하기
2. 저장된 계산 결과 출력
3. 최근 계산 결과 삭제
4. 입력받은 값보다 큰 결과값 출력        
5. 프로그램 종료
```
